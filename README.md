LiteLLM

LiteLLM is an open-source Python SDK and proxy server that provides a unified interface to interact with over 100 Large Language Models (LLMs) across various providers, including OpenAI, Azure, Anthropic, Hugging Face, AWS Bedrock, Vertex AI, Cohere, Replicate, and Groq .

🚀 Features

Unified API: Interact with multiple LLMs using a single OpenAI-compatible API format.

Proxy Server (LLM Gateway): Centralized service to manage and route requests to various LLMs, supporting load balancing, cost tracking, and rate limiting.

Python SDK: Integrate LiteLLM directly into your Python applications for seamless LLM interactions.

Cost Tracking & Budgets: Monitor usage and set budgets per project or API key.

Retry & Fallback Mechanisms: Ensure robustness by automatically handling failures and switching between providers.

Caching & Guardrails: Implement prompt caching and set up guardrails for safer deployments.

Admin Dashboard: Visual interface to monitor and manage LLM usage and configurations
